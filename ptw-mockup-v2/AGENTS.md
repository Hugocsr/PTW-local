# ptw-mockup-v2 (o app) — guia para agentes

Leia antes: `../AGENTS.md` (regras de produto), `../CONVENCOES.md` (código) e `../DESIGN.md` (UI).

## Comandos

```
npm install
npx vite --port 5175   # desenvolvimento; /api e /status.json vão ao Docker em https://localhost
npx tsc -b             # tipos
npm test               # vitest (núcleo)
npx eslint src         # zero erros; confere também as camadas e o tamanho dos arquivos (../CONVENCOES.md)
npm run check          # os três acima de uma vez
npm run build          # tsc -b && vite build
```

Antes de dar algo por pronto: `npm run check` limpo (ou `sh ../check.sh` na raiz, que inclui a API), e a tela conferida em 390/768/1024/1440. Mudou a impressão: gere o PDF e olhe.

## Convenções

- Toda tela usa `Page` + `PageHeader`; não crie larguras ou cabeçalhos próprios.
- Cor de estado só por `StatusBadge` / `TONE_*`; não escreva classes de cor soltas.
- Tamanhos de toque: `min-h-11 md:min-h-9`, ícones `size-11 md:size-9`.
- Textos com a escala `type-*` de `index.css`.
- O app usa somente a API do PostgreSQL. Recarregar preserva os registros. `/health` informa os modos de entrada: login/senha quando configurado; com `PTW_DEV_LOGIN=1`, contas ativas para demonstração e troca sem senha no cabeçalho. Cada entrada abre uma sessão real, auditada pelo servidor. Grants da sessão controlam ações administrativas; cargos continuam controlando assinaturas. Só interação humana confiável envia `/session/activity`, no máximo a cada 60 s; polling/SSE/leitura não renovam inatividade.
- Fixtures novas de teste: dados construídos pelos próprios atos das lojas (`registryStep`, `replayPermits`), com teste de cadeia íntegra e sem regra quebrada.
- O Testar do modelo usa o mesmo `StageCard` da PT real.
- **Volume** (cenário `carga`): nada de `array.find`/`filter` sobre PTs, assinaturas ou ativos por linha ou por cartão; use `core/indexes` (`byId`, `signaturesOf`, `peopleInScope`, `locationPath`). O relógio anda a cada segundo: o que depende só do dia e das contas vencidas (`accountEpoch`) não recalcula no tique, e células que seguem o relógio são componentes próprios. Tabelas grandes passam `searchText`/`columns` estáveis ao `DataTable`. A fixture de carga é exercitada em testes; o app não oferece seleção de cenário.
